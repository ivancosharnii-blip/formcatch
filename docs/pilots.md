# Этап 10. Пилоты — рабочий комплект

Пилот — настоящий маленький бизнес с сайтом, который подключает Formcatch **сам**, по инструкции из кабинета, без помощи Вани. Цель: 3–10 пилотов и честные цифры для жюри: «подключили за N сек», «получили M заявок за неделю».

---

## 1. Перед первым пилотом (делает Ваня, один раз)

- [ ] **Google Cloud → проект Formcatch → APIs & Services → OAuth consent screen → кнопка «Publish app» → Confirm.**
  Сейчас приложение в режиме Testing: войти могут только адреса из списка Test users. После Publish — любой Google-аккаунт.
  Мы просим только email и профиль (базовые scopes), поэтому проверка Google (verification) не нужна и страшного экрана «приложение не проверено» не будет.
  Проверка: выйти из кабинета, войти **другим** Google-аккаунтом (не из Test users). Должно пустить.
- [ ] Открыть https://formcatch-woad.vercel.app/ с телефона — убедиться, что кабинет открывается и вход работает.
- [ ] Подготовить секундомер — нет, не нужен: кабинет сам считает время от «Добавить сайт» до первого сигнала скрипта и пишет «✅ Сайт подключён за N сек». Пилоту достаточно прислать скриншот этой строки.

## 2. Кого звать

Нужен бизнес, у которого **есть сайт с формой заявки** и есть доступ к его редактированию (сам владелец или его «человек по сайту»). Подходит: салон, автосервис, репетитор, студия, доставка, мастер на дому.
Идеально — разные платформы: 1–2 на Tilda, 1–2 на WordPress, хотя бы 1 на **Wix** (перехват на Wix ещё не проверен, см. раздел 6), 1 «самописный».

Где искать: родители одноклассников, знакомые предприниматели, соседние заведения, местные чаты. Пилот ничего не платит; взамен — 10 минут и честный отзыв.

## 3. Памятка пилоту (текст для отправки)

> Привет! Я делаю Formcatch — бесплатный сервис, который собирает заявки с сайта в одну таблицу. Хочу проверить его на настоящем сайте. Это займёт около 10 минут, ничего ломать не надо, скрипт можно убрать в любой момент.
>
> Что нужно сделать:
> 1. Открыть https://formcatch-woad.vercel.app/ и войти через Google.
> 2. Нажать «Добавить сайт», написать название.
> 3. Скопировать код и вставить на сайт по инструкции для вашей платформы (там есть Tilda, WordPress, Wix, другой сайт).
> 4. Открыть свой сайт в браузере один раз. В кабинете появится «✅ Сайт подключён за N сек» — пришлите, пожалуйста, скриншот этой строки.
> 5. Дальше ничего не делать — заявки с сайта сами будут появляться в кабинете. Через неделю я спрошу, всё ли пришло.
>
> Если что-то не получилось или было непонятно — напишите мне на каком шаге, это самое ценное.
>
> Политика конфиденциальности: https://formcatch-woad.vercel.app/privacy.html

## 5. Цифры из базы (Supabase → SQL Editor)

Кабинет показывает каждому владельцу только его сайты. Сводка по всем пилотам — только через SQL под админом. Вставить и нажать Run:

```sql
-- Сводка по сайтам всех владельцев, кроме тестовых аккаунтов
select
  s.name                                                   as "Сайт",
  s.domain                                                 as "Домен",
  u.email                                                  as "Владелец",
  s.created_at::date                                       as "Добавлен",
  extract(epoch from (s.connected_at - s.created_at))::int as "Подключён за, сек",
  s.form_found                                             as "Форма найдена",
  count(l.id) filter (where not l.blocked)                 as "Заявок",
  count(l.id) filter (where l.kind = 'formless')           as "из них через кнопку",
  max(l.created_at)                                        as "Последняя заявка"
from public.sites s
join auth.users u on u.id = s.owner_id
left join public.leads l on l.site_id = s.id
where u.email not in ('ТВОЙ_GOOGLE_АДРЕС')  -- тестовые аккаунты, которые не считаем
group by s.id, u.email
order by s.created_at;
```

Если «Подключён за, сек» пусто — скрипт ни разу не отправил сигнал: пилот не вставил код или вставил не туда. Если «Форма найдена» = false, а на сайте форма есть — это баг перехвата, записать платформу и адрес страницы.

## 6. Если у пилота Wix

Перехват на Wix **не проверялся** (этап 3): на бесплатном тарифе нельзя вставить код, а HTML-блок Wix — это iframe и форм страницы из него не видно. Инструкция в кабинете говорит: Settings → Custom Code → вставить в Head.
Что проверить на пилоте с Wix:
1. Загрузился ли скрипт (в кабинете «Сайт подключён» появился).
2. Нашёл ли формы (`form_found` = true в запросе выше).
3. Пришла ли тестовая заявка через настоящую форму Wix.
Если шаг 2 или 3 провалился — это задача на доработку скрипта, записать в PROJECT.md.

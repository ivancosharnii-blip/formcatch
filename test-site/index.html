Formcatch — тестовый стенд

Здесь собраны разные виды форм, которые встречаются на реальных сайтах. На каждой проверяем, что скрипт перехвата делает то, что ожидается.

О нас (страница без форм) · Сайт вообще без форм

Случай 1: обычная форма

Ожидаем: заявка перехвачена, браузер переходит на страницу «Спасибо».

Случай 2: AJAX-форма с непонятными именами полей

Ожидаем: заявка перехвачена, поля названы по подписям («Ваше имя», «Телефон»), а не field_1 / field_2.

Случай 3: форма с паролем и картой

Ожидаем: перехвачены только имя и логин. Пароль, номер карты и CVC не отправляются никогда.

Случай 4: «форма» без тега <form>

Ожидаем: заявка перехвачена (так делают некоторые конструкторы сайтов).

Случай 5: форма-попап, появляется после загрузки

Ожидаем: заявка перехвачена, хотя формы не было на странице при загрузке (как попапы Tilda).

Случай 6: форма внутри iframe

Ожидаем: НЕ перехвачена. Браузер запрещает скриптам заглядывать в чужие iframe, это нормально.

Случай 7: поиск по сайту

Ожидаем: НЕ перехвачена. Поиск — это не заявка клиента.
